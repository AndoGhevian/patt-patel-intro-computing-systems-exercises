### 7.1

After first pass through program assembler create
a symbol table with labels associated to memory
addresses identified by them.

When LDI is translated on the second path Location
Counter (LC) mark its location which is x3025,
so previous LC was x3024 in which there is a value
stored with .FILL pseudo-op of assembler.

So PLACE label identifies location contained in LC when examining instruction at first pass, which means association
created PLACE -> x3024.

On the translation, which is second pass, LDI instruction
explicitly reference that location.

We can translate instruction
based on current LC which we need to know to calculate PCOffset.

PC + 1 = LC + 1 = x3025 + 1 = x3026

Now (PC + 1) + PCOffset = PLACE = x3024

So x3026 + PCOffset = x3024

PCOffset = -x2 = PCOffset9 = 111111110

So we have location x3025 contents: 1010 011 111111110
