### 7.25

.FILL pseudo-op set aside a memory location and
initialize it with value.

Well in LC-3 machine case, because memory is
word addressable, there are 2 possibilities,
1. It will give error, because xFF004 requires
20 bits
1. It will simply truncate 4 significant bits.

But we need to test it, to make sure the actual result.

```
.ORIG x3000
.FILL xFF004    ; It fails, because assembler
                ; refuse to encode provided value
                ; as 16 bit 2's complement number
.END

```
