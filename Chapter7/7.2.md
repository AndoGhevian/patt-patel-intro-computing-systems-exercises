### 7.2

Instruction will be to R1 memory contents
specified by Offset, which will lead to memory loaction
referenced by ASCII label, that is containt the instruction itself.

So it will lead to R1 be loaded with that instruction.
We need to find out instruction binary representation
to give exact contents.

At the moment instruction is examined:
ASCII = LC = x4F08

At the point of translation incremented PC is => INC(PC) = LC + 1 =
x4F08 + 1 = x4F09

So PCOffset9 = ASCII - INC(PC) = x4F08 - x4F09 = -x1 = 111111111

0010 001 111111111 = x23FF

So We will have R1 <- x23FF
