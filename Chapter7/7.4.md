### 7.4

Steps:
1. Initialize LC = x301C
1. Examine instruction: `ST R3, SAVE3` -> no label
1. continue to `TEST IN` calculating LC -> LC = x301F
1. Examine `TEST IN` -> Identify label TEST with memory
address of an entry, in this case Instruction, it is assigned to: Memory address marked for entry `TEST IN` is contained in
current LC = x301F, so `TEST = LC = x301F`. NOTE: LC tracks memory location assign to instruction that is currently examined by assembler.

So on, we have final symbol table tracking LC:

1. TEST -> x301F
1. FINISH -> x3027
1. SAVE3 -> x3029
1. SAVE2 -> x302A
