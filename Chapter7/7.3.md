### 7.3

The problem is that assembler tryes to translate
assembly language to machine language, and because
AND is an assembly language instruction, it leads
to ambiguity in the assembly language instruction itself.

Remember format:

Label Opcode Operands ; Comment

So when AND is at the first place, it is confusing wether
1. Is AND instruction following the operands OR
1. Is it a label that is following instruction

No one guaranty that R9 will not be an instruction at some point in the future.
