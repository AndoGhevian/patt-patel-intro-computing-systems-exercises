### 7.10

It is not possible to provide to ADD Opcode 6 or more
bit immediate values, so 30 is not representable in 5 bit 2's complement and hence
it will not be assembled.

And even if it will be possible somehow to generate in the program object module the bits without error, it will
lead to logic error in LC-3 simulator:

#30 = 011110 which lead to 01111 taken as literal value: #15 and
one extra left most 0 which can break the code.
