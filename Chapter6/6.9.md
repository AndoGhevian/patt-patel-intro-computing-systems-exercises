### 6.9

Iteration Construct of Structured Programming
is implemented this way:
1. Y -> Generate Condition Codes
1. 0000 ?(3 bits) X(PCOffset9) | Finish if false
1. Subtask
1. 0000 111 Y(PCOFfset9)
1. x -> next instruction

Here we have Y equal to number of instructions in a whole
construct, because each instruction represent one address.

X equal number of instructions of Subtask + 1

There are several possible implementations with
Table A.3 trapvectors corresponding to service
routines.

To output characters on a display we have several
routines:
1. OUT (x21) - one character per call
1. PUTS (x22) - string of characters where each mem location
contains a single character, with high bits zeroed.
1. PUTSP (x24) - print a string of characters where
each memory location contains pair of characters, where
first one contained in a low byte, second in a high byte.

But anyway we need a a loop to compose a string.
