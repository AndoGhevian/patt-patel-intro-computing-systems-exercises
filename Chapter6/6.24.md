### 6.24

R0 is changed and PC is set to immediately next address:

M[x3050] = x6??? = 0110 which is Base+Offset addressing mode load instruction.

So we have 0110 000 Offset9 => LDR R0, R?, SEXT6 resulting in:

R0 <- Mem[R? + SEXT6] = xFFFF

we have initialized M[x4201] = xFFFF, so we need to reach that address:

x4201 = RX + Offset6, one possible case is: R1 + 000001

There cant be any other solution because Offset gives maximum displacement
posibility of 6 bits => [-32, +31]. [-x20, +x20], which makes it
impossible to reach x4201 using base+offset addressing mode.
