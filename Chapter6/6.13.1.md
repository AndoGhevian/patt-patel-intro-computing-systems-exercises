Well shifting to right we lost last bit, so we can consider
it is 0 regardles of it is 1 or 0.

In this case because of the fact thet when adding number to
itself it results in bits representation shift to left
filling last bit with 0, which confirms to our losse
consideration of initial value to be shifted right, we
can now use this fact.

So lets find a number, which is when added to itself
gives provided value to be shifted right, where first
bit is considered 0 regardless of its original value.

when adding a column of bits we always get a 0 and weather
in given column there is 1 or 0 depends on previous bits
column addition:
1. if previous bits column contain 1's then in the current column of inital value we have 1
1. if previous column of bits contain 0s we have 0 in the current column of initial value

So lets go from given considerations backward:
1. if initial value bit is 0 then next bit of result is 0
1. If initial value bit is 1 then next bit of a result is 1

By Next Bit we mean lower bit. Also most significant bit has no effect on initial value, so it can have any content.
