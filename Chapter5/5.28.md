Because of the fact that this Indirect store depends on
value stored in some location which is a black box for a program,
and so its contents can change, we need to replace it
with instruction such that it will also depend on
provided address.

We need first to load in to some register the address from
x3004 as a base register, and then use it with base+offset mode.

So we will need 2 instructions:
1. load address
2. store into that address

1. x3000 0010 0000 0000 0010
1. x3001 0010 001 000000011 R1 <- Mem[x3005] x3004 is shift by one.
1. x3002 0111 000 001 000000 R0 <- Mem[R1]
1. x3003 1111 0000 0010 0101
1. x3004 0000 0000 0100 1000
1. x3005 1111 0011 1111 1111
