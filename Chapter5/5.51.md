### 5.51

Obviously there is additional SR1MUX to select DR as a source
for microinstructions.

For all existing instructions SR1MUX always select SR1 field
bits from IR[8:6], but here we need to be able also to select
DR which is IR[11:9] to be able to provide DR to ALU.

Here is why:

#### state 13
these are external outputs corresponding to these states, which are control signals.

1. SR1MUX = IR[8:6] (SR1)
1. ALUK = NOT
1. GateALU = 1
1. LD.REG = 1
1. DRMUX = IR[11:9]

#### state A
1. SR1MUX = IR[11:9] (IN DR)
1. ALUK = ADD
1. SR2SEL = register A, it should contain 2's complement psoitive 1.
1. LD.REG = 1
1. GateALU = 1
1. DRMUX = IR[11:9] (OUT DR)

#### state B
1. SR1MUX = IR[11:9] (IN DR)
1. ALUK = ADD
1. SR2SEL = SR2OUT
1. LD.REG = 1
1. GateALU = 1
1. DRMUX = IR[11:9]
1. LD.CC = 1
