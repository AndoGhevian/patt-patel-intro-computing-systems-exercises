#### a. What is an addressing mode?

Addressing mode is a mechanism of specifiing location where to
find operand.

#### b. Name three places an instruction’s operands might be located.

They can be located in instruction itself, immediate operand,
in register or in memory.

#### c. List the five addressing modes of the LC-3, and for each one state where the operand is located (from part b).

for "immediate addressing mode" operand is literally contained
in instruction.

for register addressing mode operand is identified by a register.

If it is source operand, then it is contained in register,
if it is destination operand, then register itself is an operand.

for PC-relative memory addressing mode operand is contained
in memory location with address specified by PC + Offset, where
Offset comprise from address generation bits of an instruction
by 2's complement integer data type application.

#### d. What addressing mode is used by the ADD instruction shown in Section 5.1.2?

3 register modes are used, 1 for destination operand and
2 for source operands.
