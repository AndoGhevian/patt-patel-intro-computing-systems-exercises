#### Explanation

First x3000: xA009 is instruction: 1010 000 000 1001 - LDI R0, #9

Then we have 2 modifications of MDR and MAR to accomplish LDI:

1. MAR <- x3001 + x9 = x300A,  MDR <- Mem[x300A]
1. MAR <- Mem[x300A], MDR <- Mem[Mem[x300A]]

So, because Mem[x300A] = x3025 prefilled, we have a new entities filled in table.

Then PC is incremented.

Here we have ADD R3, R4, R3

R3 filled ones:
1. After 1: x4002
1. After 2: R3 <- R4 + R3 = x4003 + x4002 = x8005

R3 Filled.

Also we can fill others for after 2:

1. R3: x4002, x8005
1. R5: x400D

Next is PC = x3002 but after it is executed PC is changed
to x400D, so it is obviously BR or JMP or whatever change PC.

Now, if there is a BR, then we have 9 bits, so x00FF or xFF00 for negative offset:

1. x3002 + 1 + x00FF = x3102 is a maximum
1. x3002 - x0100 < x400D

So it could be JMP (if not JSR, JSRR) OR maybe TRAP or RTI or RET
(even though RTI make no scense, since program starts execution
at x3000)

RET is not, or PC should be R7 whihc is x6001. 

We have all registers snapshot after 2, and there is a register
with value x400D, also R7 is not modified with incremented PC,
which is x3003, so it is obviously not JSR or JSRR.

TRAP cant be, because it allowes only PC to be changed maximum to x00FF.

Also because R6 is not modified like by RTI it should be JMP R5.

After 3:

1. R5: x400D

After JSRR R1 (after instruction 4):

1. R4: x4003
1. R7: x400E
1. PC = x5009

The next instruction is not a sequential instruction.

It equal to saved during JSRR R7 value -> PC = R7 = x400E

Now, here we again have to consider BR, JMP, JSR, JSRR TRAP and RTI, RET instructions.

BR cant be because x5009 - x00FF will give x4F0A > x400E

Maybe it is JMP R7 (RET).

For JSR we have 11 bits offset -> x5009 - x07FF = 0x480A > 0x400E, so it is not JSR

IT could be JSRR R7.

Obviously not TRAP and not RTI, See register stnapshots for R6 (RTI).

So it is or JMP R7 or JSRR R7.

Next instruction ADD does not modify R7.

Since after address x5009 instruction execution R7 is not modified to x500A, but still same x400E then it is obviously not JSRR R7, but JMP R7.

After 5:
1. R7: x400E
1. R4: x4003

So finally, for register file snapshots we have:

1. R3: x4002, x8005
1. R4: x4003, x4003
1. R5: x400D, x400D
1. R7: x400E, x400E
