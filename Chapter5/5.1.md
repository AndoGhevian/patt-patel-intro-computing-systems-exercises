### 5.1 Given instructions ADD, JMP, LEA, and NOT, identify whether the instructions are operate instructions, data movement instructions, or control instructions. For each instruction, list the addressing modes that can be used with the instruction.

There are no instructions listed that move data to/from memory
or input/output devices, so there are no data movement instructions.

There are 2 Operate instruction which are processing some
data and out some result, all these are controled by
processing unit, tipically in von neumann model an ALU.

These are ADD, NOT.

First note, what is an addressing mode ? Addressing mode
is a mechanism of identifing location, eather register,
memory location or even immediate location inside instruction.

Second note, as i understand from book addressing mode does not
refere to process of obtaining data itself, so it is not performed in FETCH OPERANDS phase, but before it.

So, ADD instruction, depending on bit [5] of its representation
could have different addressing modes.

for destination operand and first source operand register mode is used.

For second source operand if bit [5] is 1 then register mode is used, otherwise immediate mode is used.

There is LEA, which is not operate on data, but rather move
address calculated at EVALUATE ADDRESS phase into GPR (General Pourpose Register). For calculating its address it is using
PC+PCoffset memory addressing mode. Then it put this address
into GPR specified by bits [11, 9] using register mode.

Control instrctions are used to break sequential instruction
execution flow by modifiing Program Countter (PC). JMP is such.

JMP instruction use Base+Offset memory addressing mode
to identify location address by which to change PC, so
breaking execution flow.
