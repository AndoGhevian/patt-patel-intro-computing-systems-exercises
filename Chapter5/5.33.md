### 5.33

at the end of execution R0 = 5.

R5 ?=

1. x2FFF 0101 000 000 1 00000 R0 <- 0
1. x3000 0101 111 111 1 00000 R7 <- 0
1. x3001 0001 110 111 1 00001 R6 <- R7 + 1
1. x3002 0101 100 101 000 110 R4 <- R5 AND R6
1. x3003 0000 010 000000001 BRz x3005
1. x3004 0001 000 000 1 00001 R0 <- R0 + 1
1. x3005 0001 110 110 000 110 R6 <- R6 + R6
1. x3006 0001 111 111 1 00001 R7 <- R7 + 1
1. x3007 0001 001 111 1 11000 R1 <- R7 - 8
1. x3008 0000 100 111111001 BRn x3002
1. x3009 0101 111 111 1 00000 R7 <- R7 AND 0

Lets express it as an algorithm:
```
R0 = 0; R7 = 0; R6 = 1

do {
  // R4 <- R5 AND R6
  if(R5 AND R6) {
    R0 <- R0 + 1
  }

  R6 <- R6 + R6 <=> ShiftLeft(R6)
  R7 <- R7 + 1
  // R1 <- R7 - 8
} while(R7 - 8)
// R7 <- 0
```

I have commented out unnecesery code:
```
R0 = 0; R7 = 0; R6 = 1

do {
  if(R5 AND R6) {
    R0 <- R0 + 1
  }

  R6 <- ShiftLeft(R6)
  R7 <- R7 + 1
} while(R7 - 8 < 0)
```

Loop will do 8 iterations and each time if next bit of R5
starting rom right will be equal to 1 R0 will be incremented,
else not.

So will be checked 8 bits from right.

Given R0 = 5, we can say that exactly 5 bits are set and 3 are cleared.
