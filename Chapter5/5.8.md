### 5.8 We want to increase the number of registers that we can specify in the LC-3 ADD instruction to 32. Do you see any problem with that? Explain.

To identify some number of entities in the instruction we need enough bits.

to identify set of 32 registers we need 5 bits at least to identify 32 codes corresponding to these registers.

Now with ADD, we have possibility of specifing 3 register operands for 1 destination and 2 source operands.

16 bits (whole) - (4 bits (opcode) + 5 bits (destination field)) = 7 bits

in 7 bits we can fit maximum 1 register field and rest 2 bits
will be not enough even for resonable immediate value operations.

So it make no scense.
