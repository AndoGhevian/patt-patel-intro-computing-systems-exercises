### 5.52

Here are isntructions that write to GPR at some point during
instruction cycle.

First Line:
1. ADD
1. AND
1. LEA
1. LD
1. LDI
1. JSR - see Appendix A. R7 is modified

These are not: BR, JMP

Second Line:
1. LDR
1. NOT
1. RTI - R6 <- SavedUSP (User Stack Pointer) is modified if RTI returns to User mode
1. TRAP - R6 is loaded with SPP if interrupt from User mode
1. reserved - cause an illegal opcode exception, and R6 is loaded System Stack Pointer

ST, STI, STR are not.
