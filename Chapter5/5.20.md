### 5.20 If we made the LC-3 ISA such that we allow the LD instruction to load data only ±32 locations away from the incremented PC value, how many bits would be required for the PC-relative offset in the LD instruction?

to support -32 it will be enough 6 bits, but in this case we will
be able to support maximum 31 positive integer, so we need 1 more bit.

answer: 7 bits.

But in this case it will not be only ±32 locations, but much more.

So now let's revisit question and solution.

if we consider 0 offset as 1 location away from PC+1 of difference 0, then we can support this range.

and we will need then 6 bits -> [-32; 31] range, where
0 is also considered location away by 0.
