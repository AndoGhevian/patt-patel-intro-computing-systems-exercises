### 5.15 State the contents of R1, R2, R3, and R4 after the program starting at location x3100 halts.

We will not draw a memory contents, see it in book.

as we know trap vector for halt a computer system call
invokation from Operating system is x25.

In this program we see this system call invokation
at address x3104.

we have registers affected by:
1. R1 x3100 -> LEA R1, #x20
1. R2 x3101 -> LD R2, #x20
1. R3 x3102 -> LDI R3, #x20
1. R4 x3103 -> LDR R4, R2, #1

R1 is a result of addition (PC +Offset) = x3101 + x20

R1 is x3121

R2 is a contents of x3102 + x20 = x3122

which is "0100 0101 0110 0110" which is not an instruction JSRR, see LC-3 instruction forms table Figure 5.3:

R2 = x4366

R3 is a contents of address located at address x3123, which is
0100 0101 0110 0111 = x4367.

Now in address x4367 we see from memory contents table in the book a value 1010 1011 1100 1101 = xABCD in R3.

R4 has contents of address formed by R2 + 1 = x4367

which is the same as we find out for R3, that is xABCD
in R4.
