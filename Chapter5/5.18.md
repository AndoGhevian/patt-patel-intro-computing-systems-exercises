### 5.18 The program counter contains the address of an LDR instruction. In order for the LC-3 to process that instruction, how many memory accesses must be made? Repeat this task for STI and TRAP.

#### LDR

1 (fetch) + 1 (read calculated address base + offset) = 2

#### STI

1 (fetch) + 1 (read contents of PC+Offste which is another address) + 1 (write location by previously read from memory address) = 3

#### TRAP

1 (fetch) + 1 (fetch address inside Operating System memory range using zero-extended trapvector to access OS service) = 2

after service call finishes PC set to next after TRAP instrction, no memory access happening in the given instruction cycle.
