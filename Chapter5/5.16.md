### 5.16 Which LC-3 addressing mode makes the most sense to use under the following conditions? (There may be more than one correct answer to each of these; therefore, justify your answers with some explanation.)

a. You want to load one value from an address that is less than ±2^8 locations away.

with PC-relative load we have 9 bits offset bits to form
2's complement integer, i.e. to cover range relative to PC:

[-(2^8 - 1); 2^8] so it conforms to requirement of less than
"±2^8 locations away".

So we can use load with PC-relative addressing mode.

b. You want to load one value from an address that is more than 2^8 locations away.

From previous point explanation it is explicit that PC-relative
mode is not appropriate.

We can use here a base+offset mode with simplification:

If we need more than 2^8 we can use:
1. offset 011111111
1. base-contents >= integer 1

If we need less than 2^8:
1. offset 100000000
1. base-contents < integer -1

Or given it is one value, we can simply put it at some address
and use indirect mode with that address.

e.g.

1. R1 <- x101
1. ST R1, x010
1. LDI R1, x00F

this instruction now loads contents from x101 which is impossible
with PC-relative load from offset x0FF

c. You want to load an array of sequential addresses.

We can use 2 methods, 1 manual access to each element,
and 2 dynamic access to get reusable instructions sequence
to use as a loop body.

We can use base-offset addressing mode by setting start as
base and for each manual access adjast offset by the size of
an element.

OR

We can set base register with a start address of an array element and then adjust base according to the size of an element,
and all this using LEA, ADD, and LDR instructions.
