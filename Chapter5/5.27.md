### 5.27 Before the seven instructions are executed in the example of Section 5.3.4, R2 contains the value xAAAA. How many different values are contained in R2 during the execution of the seven instructions? What are they?

1. R2 <- xAAAA
1. x30F6 R1 <- x30F4
1. x30F7 R2 <- R1 + 14 = x3102
1. x30F8 Mem[30F4] <- R2
1. x30F9 R2 <- 0
1. x30FA R2 <- R2 + 5 = 5
1. x30FB Mem[x3103] <- R2
1. x30FC R3 <- indirect addressing mode, (this is not interesting to us)

R2 = [xAAAA, x3102, 0, 5], 4 different values.
