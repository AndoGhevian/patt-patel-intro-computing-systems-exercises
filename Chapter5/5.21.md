### 5.21 What is the maximum number of TRAP service routines that the LC-3 ISA can support? Explain.

Essentially there identifiable 2^8 addresses for 8 bit LC-3 trapvector.

So if there are a single instruction inside each service call,
except the instruction that sets back the PC to next user program instruction, we would have at least 2 instructions per
service call in memory inside Operating System.

So we will have 2^8 / 2 = 2^7 = 128

Or in the worst case, if these are not impelmented, they can immediately return to save PC, which would be 256 empty
service calls.
